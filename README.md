# iSwim CRM

CRM школы плавания iSwim: тренеры отмечают посещения и принимают наличные, администратор ведёт детей, оплаты EPOS и резерв, директор видит деньги, зарплаты и журнал.

- Приложение: React + Vite, ставится на телефон как приложение (PWA).
- База и вход: Supabase (проект `iSwin-CRM`). Все правила (списания, абонементы на 30 дней, права ролей) — в самой базе.
- Вход сотрудника: телефон + пароль (временный при первом входе).

Запуск локально: `npm install`, затем `npm run dev`.
